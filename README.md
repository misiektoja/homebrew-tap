# misiektoja Homebrew tap

Homebrew casks for command line tools by [misiektoja](https://github.com/misiektoja).

## Install

```bash
brew install misiektoja/tap/certrally
```

Or add the tap once and install by name:

```bash
brew tap misiektoja/tap
brew install certrally
```

`brew upgrade` updates the installed casks.

## Casks

| Cask | Description |
|---|---|
| [certrally](https://github.com/misiektoja/certrally) | Command line client for certificate enrollment with CMP and EST |

Each project's release workflow writes its cask to `Casks/`. Report problems with a cask in the repository of that project.
